# 食安哨 · AI 食堂巡检原型（在线体验版）

食品安全 AI 巡检原型，用于 iCAN 大赛「AI 产品实现」方向作品展示。

## 在线访问
GitHub Pages 地址：https://<用户名>.github.io/<仓库名>/

## 说明
- 纯静态页面，无需构建，直接由 GitHub Pages 发布根目录即可。
- 样例摄像头画面位于 `images/`，已内嵌路径映射，无需额外配置。
- 「上传画面 → 开始识别」会调用云端视觉模型服务（腾讯云 CloudBase 云函数 + 智谱多模态模型）。
  若模型服务不可用，页面会自动降级为示例结果并明确标注，不影响流程演示。
- 示例数据与 AI 生成的示意图均在界面上标注来源，不代表真实巡检结论。

## 技术栈
- 前端：单文件 HTML + 原生 JS + ECharts
- 识别：多模态视觉大模型（glm-4v-flash），经服务端代理调用，前端不保存任何密钥
- 数据存储：浏览器 localStorage（演示用）
